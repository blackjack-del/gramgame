💡 3 ข้อจำง่าย (Shortcut)
1
ปฏิเสธหรือคำถามด้วย do, does, did, will:

2
อนาคต (Future): ประธานทุกตัวใช้
will / won't เหมือนกันหมด
3
อดีต (Past): กริยาทั่วไปใช้ did / V.2 เหมือนกันหมด มีแค่กลุ่ม was / were ที่แยกตามประธาน

🕒 ปัจจุบัน
(Present)
บอกเล่า: am / is / are / do / does + V.1
ปฏิเสธ: am not / isn't / aren't / don't / doesn't
คำถาม: Am/Is/Are ...? / Do/Does ...?
📅 อดีต
(Past)
บอกเล่า: was / were / did + V.2
ปฏิเสธ: wasn't / weren't / didn't
คำถาม: Was/Were ...? / Did ...?
⏩ อนาคต
(Future)
บอกเล่า: will + V.ธรรมดา
ปฏิเสธ: won't + V.ธรรมดา
คำถาม: Will ...?
