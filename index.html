# ประธาน (Subject) บริบท 🕒 ปัจจุบัน (Present) 📅 อดีต (Past) ⏩ อนาคต (Future)
1I(ฉัน)บอกเล่า am / do
V.1 ไม่เติม s		 was / did / V.2 will + V.ธรรมดา
2ปฏิเสธ don't / am not didn't / wasn't won't + V.ธรรมดา
3คำถาม Do I...? / Am I...? Did I...? / Was I...? Will I...?
4You(คุณ/พวกคุณ)บอกเล่า are / do
V.1 ไม่เติม s		 were / did / V.2 will + V.ธรรมดา
5ปฏิเสธ don't / aren't didn't / weren't won't + V.ธรรมดา
6คำถาม Do you...? / Are you...? Did you...? / Were you...? Will you...?
7He / She / It(เอกพจน์)บอกเล่า is / does
V.1 เติม s/es		 was / did / V.2 will + V.ธรรมดา
8ปฏิเสธ doesn't / isn't didn't / wasn't won't + V.ธรรมดา
9คำถาม Does he...? / Is he...? Did he...? / Was he...? Will he...?
10We / They(พหูพจน์)บอกเล่า are / do
V.1 ไม่เติม s		 were / did / V.2 will + V.ธรรมดา
11ปฏิเสธ don't / aren't didn't / weren't won't + V.ธรรมดา
12คำถาม Do they...? / Are they...? Did they...? / Were they...? Will they...?
💡 3 ข้อจำง่าย (Shortcut)
1
ปฏิเสธหรือคำถามด้วย do, does, did, will:
กริยาแท้ใช้รูปธรรมดา (V.base) เสมอ ไม่ต้องเติม s และไม่ต้องเป็น V.2
2
อนาคต (Future): ประธานทุกตัวใช้
will / won't เหมือนกันหมด
3
อดีต (Past): กริยาทั่วไปใช้ did / V.2 เหมือนกันหมด มีแค่กลุ่ม was / were ที่แยกตามประธาน
โครงสร้างหลักในแต่ละ Tense
🕒 ปัจจุบัน
(Present)
บอกเล่า: am / is / are / do / does + V.1
ปฏิเสธ: am not / isn't / aren't / don't / doesn't
คำถาม: Am/Is/Are ...? / Do/Does ...?
📅 อดีต
(Past)
บอกเล่า: was / were / did + V.2
ปฏิเสธ: wasn't / weren't / didn't
คำถาม: Was/Were ...? / Did ...?
⏩ อนาคต
(Future)
บอกเล่า: will + V.ธรรมดา
ปฏิเสธ: won't + V.ธรรมดา
คำถาม: Will ...?
